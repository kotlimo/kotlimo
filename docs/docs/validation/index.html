Validation

Validate incoming request data with Laravel-style rule strings before it ever touches your models.

Rules

Supported rules include required, email, min, max, integer, numeric, boolean, confirmed, in, url, same, and regex.

val validator = Validator.make(data, mapOf(
    "email" to "required|email",
    "password" to "required|min:8|confirmed"
))

if (validator.fails()) {
    return Response.json(mapOf("errors" to validator.errors()), 422)
}
