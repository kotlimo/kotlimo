Queues

Jobs implement Job and expose handle(). The sync driver runs work immediately. The array driver stores jobs in memory until queue:work.

class WelcomeMail(val email: String) : Job {
    override fun handle() {
        Mail.send(email, "Welcome", "<p>Hi</p>")
    }
}

dispatch(WelcomeMail("ada@example.com"))
Queue.push(WelcomeMail("ada@example.com"))
./gradlew run --args='queue:work --once'

There is no Redis/database worker and no delayed retry backend. later(seconds, job) is honored by the array driver; sync still runs immediately.
