Mail

Mail does not require an SMTP server. The log driver writes a line to the application logger. The array driver stores messages in memory for tests.

Mail.send("ada@example.com", "Welcome", "<p>Hello</p>")

Mail.send {
    to("ada@example.com")
    subject("Welcome")
    html("<p>Hello</p>")
}

Set MAIL_DRIVER=array in tests and inspect app.make(ArrayMailer::class).messages.
