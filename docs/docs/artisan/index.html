Craft CLI

Craft is Kotlimo's command runner. Inside an application, invoke it through that app's Gradle run task. From this repository you can also scaffold apps with the console module.

Create an app

./gradlew :kotlimo-console:run --args='new blog'
./kotlimo new blog

Application commands

./gradlew run --args='list'
./gradlew run --args='serve --port=8000'
./gradlew run --args='route:list'
./gradlew run --args='migrate'
./gradlew run --args='migrate:rollback'
./gradlew run --args='make:migration create_posts_table'
./gradlew run --args='make:controller UserController'
./gradlew run --args='make:model Post'
./gradlew run --args='key:generate'
./gradlew run --args='schedule:run'
./gradlew run --args='queue:work --once'

This documentation site is itself an app, so the same commands work as ./gradlew :website:run --args='route:list'.

What they do

  • list — show registered commands
  • serve — start the Kotlin development server
  • route:list — print HTTP routes
  • migrate / migrate:rollback — run JSON files in database/migrations
  • make:migration / make:controller / make:model — generate starters
  • key:generate — write APP_KEY into .env
  • schedule:run — run due scheduler callbacks
  • queue:work — drain the in-memory array queue
  • site:export — write static HTML for GitHub Pages (website module only)

Custom commands

class PingCommand : Command() {
    override val signature = "ping"
    override val description = "Print pong"
    override fun handle(): Int {
        line("pong")
        return 0
    }
}

app.make(ConsoleKernel::class).register(PingCommand())
