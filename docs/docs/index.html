Installation

Kotlimo is an open-source Kotlin web framework. Clone the repository, run the tests, and boot the included website application.

Requirements

  • JDK 21 or newer
  • The Gradle wrapper in this repository (./gradlew)

Clone and run

git clone https://github.com/kotlimo/kotlimo.git
cd kotlimo
./gradlew test
./gradlew :website:run

The development server starts at http://127.0.0.1:8000. This documentation site is the website/ module — a Kotlimo application.

Craft commands

Craft is invoked through Gradle. There is no published kotlimo binary yet.

./gradlew :website:run --args='list'
./gradlew :website:run --args='route:list'
./gradlew :website:run --args='make:controller PostsController'

Application skeleton

val app = Application.create(basePath)
    .withDefaultProviders()
    .boot()

Route.get("/") { view("home", mapOf("title" to "Kotlimo")) }

app.run(arrayOf("serve"))

Configuration

Copy website/.env.example to website/.env for local overrides. Nested config is stored under config/*.json and read with dot notation: Config.string("app.name").
