The Kotlin Framework
for Web Artisans

Kotlimo is a web application framework with expressive, elegant syntax. It gives Kotlin an IoC container, routing, Blade-like views, an Eloquent-style ORM, sessions, CSRF, auth, validation, queues, mail, and a Craft CLI.

$ ./gradlew :website:run

Route.get("/users/{id}") { request ->
    val user = User.findOrFail(request.route("id"))

    view("users.show", mapOf(
        "user" to user
    ))
}

A progressive framework

Kotlimo grows with you. Start with routing, views, and a service container. When you are ready, reach for Eloquent-style models, validation, migrations, caching, events, and the Craft CLI — without leaving the happy path.

  • Expressive routing and middleware
  • Constructor auto-wiring IoC container
  • Query builder and Active Record models
  • Sessions, CSRF, and session-based auth
  • Kote templates with Blade-like syntax
class UserController {
    fun store(request: Request): Response {
        val data = request.validate(mapOf(
            "name" to "required|string|max:255",
            "email" to "required|email"
        ))

        val user = User.create(data)

        return redirect("/users/" + user.id)
    }
}
class User : Model() {
    override val fillable = listOf("name", "email")

    fun posts() = hasMany(Post::class)

    companion object : ModelCompanion<User>(User::class)
}

val user = User.find(1)
val posts = user?.hasMany(Post::class)
